# 1000+ icon launch plan

The existing 12 hand-built Classic/Noir vectors stay in the product.

Catalog priority:
1. Google + Samsung system apps
2. Meta, WhatsApp, Instagram, TikTok, YouTube, Spotify
3. Microsoft, Amazon, Netflix, PayPal
4. Telegram, Discord, Reddit, X, Snapchat
5. ChatGPT, Claude, Gemini, GitHub and developer tools
6. German/EU popular banking, transport, shopping and media apps
7. Long-tail apps based on icon requests

Each supported app can map to multiple DarkFrame collections without duplicating navigation architecture. Missing apps use a consistent themed container/mask where the launcher/API permits; DarkFrame never pretends an unsupported component is supported.

Target: 1000+ distinct supported app identities, then expand style variants independently.
