# DarkFrame Icons

Premium dark Android icon pack.

## Vision
DarkFrame starts with **Classic Outline**: deep-black rounded tiles, crisp light outlines and simplified monochrome glyphs. Future collections can add AMOLED, Glass and Chrome variants while keeping one coherent grid.

## Status
Initial Android scaffold. Original artwork only; third-party trademarks remain property of their owners.

## Build
Open with Android Studio (JDK 17) or run `./gradlew assembleDebug` once the Gradle wrapper is generated/synced.
